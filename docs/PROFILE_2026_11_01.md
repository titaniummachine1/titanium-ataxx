## Result
- Quiet single-thread nps of main is **110k-148k in real positions (162-169k at the start position)**, i.e. **~6-9 us per node in total**. D167's 69-103 knps was measured with 4 gate workers on a hyperthreaded 4C/8T box and/or an older build, and D188's "eval = 9.5 us" cannot be true now (the whole node costs 6-9 us). Per-component split (extraction / accumulate / cache / head) is therefore STALE and must be re-profiled; I did not do that here.
- In real gates the engines get roughly half a core each (7-8 parallel games on 4C/8T): that is why game logs show ~60 knps (e.g. 5210 nodes / 86 ms in a 100 ms gate). Never read nps from a parallel gate log as engine speed.
- NOT re-measured: Zataxx (1.4-1.8 Mnps, D167, same caveat: measured by me earlier under unknown load; its exe was not found quickly). So the "17-20x" ratio is unverified; with Titanium at 110-148k the ratio would be ~10-16x IF the Zataxx figure holds. The -354 Elo at 100 ms (D166/D167) is a game result and still stands for the build that played it; it was not re-run.
